# CLAUDE.md — Frontend UI/UX Design System & Standards

This directory contains the Next.js 16 App Router frontend for **SANKET · AI**.

## Core UI/UX Directives for Claude:
1. **Never create plain/MVP UIs**: Every component must look like a high-end, defense-grade industrial platform with tailored dark mode styling, glassmorphism (`backdrop-blur-md`), and subtle 1px border glow.
2. **Typography**: Use modern sans-serif fonts for UI (`Inter`, `Outfit`) and monospace fonts for telemetry numbers (`JetBrains Mono`, `tabular-nums`).
3. **Color Palette**: Deep Obsidian (`#0B0F17`), Slate (`#111827`), Crimson SIF Hazard (`#EF4444`), Amber Warning (`#F59E0B`), Electric Blue (`#3B82F6`), Emerald Air-Gap (`#10B981`).
4. **Motion**: Subtle micro-interactions on hover, active state depressions, and pulsing beacons for real-time WebSocket streams.
5. **Ergonomics**: High visual hierarchy, 3-second comprehension rule for control room operators, and clear icon + label status badges.
