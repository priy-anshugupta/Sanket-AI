## Design Directives
1. **Never Build Plain/MVP UIs**: Every screen must have a visual "WOW factor" with curated color harmonies, crisp typography (`Inter`, `JetBrains Mono`), and glassmorphism.
2. **Real-Time Telemetry & Motion**: All real-time telemetry elements (WebSocket alerts, live sirens, air-gap status) must feature smooth transitions and animated status indicators.
3. **Ergonomic Safety Architecture**: Ensure high visual hierarchy so control room operators and safety officers can triage SIF risks in $<3$ seconds.
